**Figure 1. Data and method relationships in the cross-species prediction analyses.** **a**, Treated and matched-control measurements define within-species response differences, which are aligned through shared orthologues. The primary TG-GATEs analysis uses bulk condition means. **b**, Kernel ridge regression combines the chemical and planned-exposure prior kernel, Kp, and rat-response kernel, Kr, with fixed equal weights. It includes the human training-mean intercept. The fold glyph shows one outer split: four training folds and one test fold. Within the training pool, one inner split uses two fitting folds and one tuning fold. Roles rotate across five outer and three inner folds. Inner folds select regularization; imputation, scaling and kernel transformations use the corresponding training partition. The prior-only model omits Kr. The external-study model retains this kernel family while refitting a shared gene axis and continuous exposure context using TG-GATEs labels only. **c**, Correct or mismatched animal correspondence is evaluated separately during fitting and at query time, together with the chemical/exposure-only reference. All five predictors are compared with the same reserved human endpoints. Mismatch mappings remain within the relevant fitting, validation or query partition and the prespecified exposure strata. Repeated mismatch runs measure negative-control sensitivity using the same biological samples. Tile grids, fold blocks and pairing symbols are schematic. Cell artwork provides generic schematic symbols.
